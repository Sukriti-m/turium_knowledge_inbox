# Turium Knowledge Inbox

A small single-user knowledge inbox for saving notes or URLs and asking cited questions over the saved content.

## Development

1. Copy `.env.example` to `server/.env` when backend configuration is needed.
2. Run `npm install` at the repository root.
3. Run `npm run dev` to start the React client on `http://localhost:5173` and the API on `http://localhost:3001`.
